A v12 table walkthrough

Build the table in pieces

A table begins as a JSON scaffold with empty places for its columns, headings, rows, and footer. Data and templates fill those places. The finished JSON can be inspected on its own, then converted into browser DOM.

1

Start with the table shape

table.json sets the order and nesting: colgroup, thead, tbody, and tfoot. Its child arrays are the insertion points.

2

Supply data and templates

sampleData.json has column widths, column names, and records. sampleSpec.json describes how each repeated part looks.

3

Inspect, then render

v12 fills the scaffold and returns finished JSON. json-to-tag turns that same tree into the visible table.

In samples/tableTypes/v12/html/footer, the instruction-driven footer module clones the scaffold and fills the header and footer paths. This walkthrough also fills the colgroup and body, so you can see the complete table come together from the same data, templates, and scaffold. Source files: data, templates, scaffold, and instructions.

Rendered table

Header and footer controls come from the column list; body cells come from each record.
