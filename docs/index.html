Build reusable tables from data

This repo focuses on the table context: turning column definitions and row records into a consistent, template-driven table structure.

Keep table content separate from table layout

tableFromData assembles a JSON tag tree so the same table design can be reused with different datasets. Your app controls the templates and table scaffold; a separate renderer creates the browser elements.

ColumnsProvide the labels used to build the table header.
RowsProvide record values that become repeated body cells.
Templates + scaffoldDefine cell markup, attributes, and the surrounding table structure.
