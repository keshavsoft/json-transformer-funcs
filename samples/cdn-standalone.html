How This Works Under the Hood

  1. Data + Templates: Columns & rows from data are merged into cell and header templates using transformer functions.
  2. Compiled Spec Tree: An abstract JSON element specification is generated containing tagName, attributes, and nested children.
  3. DOM Generation: https://keshavsoft.github.io/json-to-tag/dist/v9/min.js transforms the JSON tree into live HTML elements and appends them to #table-mount-point.
