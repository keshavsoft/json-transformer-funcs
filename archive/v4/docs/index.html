Build a table from your data

Give the library column definitions, row records, and optional JSON templates and table structure. It returns a JSON description of the table. Choose a renderer when you want browser elements.

Quick start See JSON and DOM About the renderer

What you provide

Keep the records, repeated markup, and table layout independent so the same design can be reused with different data.

Columns and rows

Columns provide heading contexts. Each row is a record whose values become body cells.

Templates

JSON tag objects describe headings and cells. Placeholders such as ${columnName} are filled from the current data context.

Table structure

A scaffold sets the outer tags, classes, and insertion points. Defaults cover a header and body.

Quick start

Install the package, build a table tree, then pass it to a renderer if your application needs DOM.

Install

npm install json-transformer-funcs
# Optional, if you want to render DOM:
npm install @keshavsoft/json-to-tag

Build and render

With the default templates and scaffold, only inData is required. The API guide shows how to customize either optional input.

import { tableFromData } from "json-transformer-funcs";
import buildSpecElement from "@keshavsoft/json-to-tag";

const inData = {
  columns: [
    { columnName: "Product" },
    { columnName: "Price" }
  ],
  rows: [
    { product: "Drill bit", price: "$12.50" },
    { product: "End mill", price: "$89.00" }
  ]
};

const tableTree = tableFromData({ inData });
const tableElement = buildSpecElement(tableTree);
document.querySelector("#table-host")
  .appendChild(tableElement);
Body cells follow each record's value order. Keep that order aligned with the columns because the current builder does not match row fields to column names.
